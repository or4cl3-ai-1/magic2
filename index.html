Get Started

One command away

Pure Python + NumPy at the core. Optional Flask, TensorFlow, DEAP when you want them.

terminal
# Clone and enter
git clone https://github.com/or4cl3-ai-1/magic2.git
cd magic2

# Core dependency only
pip install numpy

# Multi-agent collaboration
python main.py --multi-agent

# Evolutionary architecture search
python main.py --arch-search

# Interactive interface
python main.py --ui
